# سمير: صديق صوتي لأندرويد

تطبيق يعمل في الخلفية: تناديه باسمه فيسمعك، ويرد عليك بالصوت عن طريق OpenRouter.

## بناء التطبيق (مجاناً عبر GitHub)

1. أنشئ مستودعاً جديداً على GitHub، مثلاً `samir-app`.
2. ارفع كل محتويات هذا المجلد إليه (Add file ← Upload files).
   - إذا لم يُرفع مجلد `.github` (المجلدات المخفية لا تُرفع أحياناً)، اختر Add file ← Create new file،
     واكتب في اسم الملف `.github/workflows/build.yml`، والصق محتوى الملف نفسه.
3. افتح تبويب **Actions** وانتظر انتهاء البناء (حوالي 5 دقائق).
4. افتح **Releases** في صفحة المستودع من الهاتف، ونزّل `Samir.apk`.
5. ثبّته، واسمح بتثبيت التطبيقات من مصادر غير معروفة إذا طُلب منك.

## أول تشغيل

1. افتح التطبيق، ثم الإعدادات، والصق مفتاح OpenRouter.
   النموذج الافتراضي `openrouter/free` مجاني (حوالي 50 رسالة يومياً).
2. اضغط «اسمح له بالعمل في الخلفية دائماً» ووافق.
3. اضغط «تشغيل سمير» واسمح بالميكروفون والإشعارات.
4. نادِ «سمير» ثم تكلّم، أو قل «سمير شلون الجو اليوم» دفعة واحدة.
   بعد كل رد يبقى يسمعك 10 ثوانٍ بدون نداء.

## ملاحظات

- يحتاج تطبيق **Google** وخدمة **Speech Services by Google** محدّثَين، مع اللغة العربية.
- يظهر إشعار دائم أثناء الاستماع، وهذا شرط من أندرويد. أوقفه من زر «إيقاف» في الإشعار.
- هواتف Xiaomi وHuawei وOppo وSamsung: فعّل «التشغيل التلقائي» واختر «بلا قيود» للبطارية،
  وإلا قد يوقفه النظام.
- بعد إعادة تشغيل الهاتف افتح التطبيق واضغط تشغيل؛ أندرويد يمنع تشغيل الميكروفون تلقائياً عند الإقلاع.
- الاستماع المستمر يستهلك البطارية والإنترنت.
